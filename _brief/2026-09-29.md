## [Anthropic 发布 Claude Sonnet 5.5：Terminal-Bench 从 10.3% 跳到 70.6%](https://www.anthropic.com/claude-sonnet-5-5)

Sonnet 5.5 是 Claude 5.5 家族的第二个模型，定位为 Opus 5.5 的低成本高速补位，擅长范围明确的日常任务、修 bug 和产出文档表格。在 agentic 编码基准 Terminal-Bench 4.0 上得 70.6%，而 Sonnet 5 只有 10.3%；在真实职业任务评测 GDPval-AA 上仅比 Opus 5.5 低两分，且是首个仅凭截图通关《宝可梦 红》的 Sonnet。定价与 Sonnet 5 持平（输入 \$2/百万 token、输出 \$10/百万），但完成同样任务所需 token 大幅减少，实测单任务成本低约 30%，生成速度快 30% 以上。因网络安全能力已接近 Opus 5，它是首个带完整网络安全防护栏发布的 Sonnet。

**推荐理由**：同代小模型 agentic 编码分数翻近七倍而价格不变，是"次一档模型够用"这一判断的最新证据。

**推荐理由**：由政府机构而非厂商自评给出的反向证据，且指出"模型越强，越知道自己在被测"这一让评测本身失效的机制。

## [谷歌用 Gemini 把 giflib 从 C 重写成 Rust，并用 3000 万张真实 GIF 验证](https://bughunters.google.com/blog/scaling-memory-safety)

谷歌安全团队公开了一次把 C 依赖库自动迁移到内存安全语言的试点：目标是 giflib，产出是 ABI 兼容、可直接替换原库的 Rust 实现。流程分三段——先由 Gemini 做一次性整体翻译，再迭代修复 FFI 边界问题，最后接入自主验证反馈回路让模型自己跑测试并改。验证规模是这次试点的重点：用 3000 万张真实世界 GIF 和两亿次以上的差分测试来确认新实现与原库行为一致。官方博客把它定位为"规模化内存安全"的方法论探索，即用 LLM 把历史 C/C++ 依赖批量搬到 Rust，而不是逐个手工重写。

**推荐理由**：内存安全迁移长期卡在人力成本上，把 LLM 用在这种有强验证信号的翻译任务上，是目前最说得通的落地方向之一。

## [Cloudflare 发布 cf：为 agent 重写的全 API 命令行，agent 已占 Wrangler 用量 48%](https://blog.cloudflare.com/cloudflare-cf-cli-launch/)

Cloudflare 公布了一组少见的内部数据：2026 年 3 月 agent 已占 Wrangler 使用量的四分之一（前一年还是个位数百分比），上周达到 48%；agent 每天使用的不同命令数量约为人类的两倍，用到六个以上命令的概率接近四倍。而 Wrangler 只覆盖约 280 个操作，Cloudflare 的 API 有数千个。新 CLI `cf` 因此按 agent 的使用习惯重做：内置命令搜索与引导让 agent 自己找到需要的命令，JSON 是默认接口（给人类美化打印、给 agent 压缩输出以省上下文），配置格式换成 `cloudflare.config.ts` 以借助 TypeScript 的类型检查和 LSP，本地开发默认切到 Vite。目前为公开测试版。

**推荐理由**：这是第一份公开的"agent 已成为 CLI 主要用户"的量化证据，工具链为机器而非人类重新设计的拐点正在发生。

## [Jeff：用一台工作站 GPU 在家训出的 0.8B 决策模型，单次判断约 22 毫秒](https://github.com/firelex/jeff)

Jeff 是对 Qwen3.5 和 Gemma 4 的微调，做零样本分类：你用自然语言描述情境并列出选项，模型一次前向传播返回每个选项的校准概率，不生成文本也无需解析，RTX PRO 6000 上约 22 毫秒、Apple M4 Max（MLX）上约 28 毫秒。它采用与 TypeSafe AI 的 Jev 相同的请求格式但属独立项目。作者强调全程在本地硬件完成：0.8B 训练约 2 小时、2B 约 3.5 小时，合成训练数据由开源模型 Qwen3.8-Flash-Next 在两台 DGX Spark 上生成，闭源模型仅用于抽检数据质量。零样本不够用时，短时微调收益很大——其语音导航微调在单 GPU 上不到半小时把留出集准确率从 31.7% 提到 95.8%。

## [上海 AI Lab 发布 InternW0-Δ：用两万小时开放数据把视觉动态与动作生成统一起来](https://arxiv.org/abs/2609.31394)

## [Git v2.56.0 发布：refs 工具箱可增删改名，实验性 git history 新增 drop 子命令](https://lwn.net/Articles/1097213/)

本次发布集中在工作流与易用性。`git refs` 扩充了 `create`、`delete`、`update`、`rename` 四个子命令，可直接操作引用；实验性的 `git history` 新增 `drop` 子命令，删除某个提交并把其后代重放到父提交上。日常体验方面：`git status` 在本地分支落后或分叉时的建议改为提示 `git pull <remote> <branch>`；误写 `git push origin/main` 或 `git branch origin main` 现在会被识别为疑似笔误并给出更正建议；`git log --follow` 改善了对非线性历史中同一路径在多条分支上被重命名成不同名字的处理；`git log --graph` 会在视觉上区分无父提交的根提交。另外 `-h`/`--help` 现在退出码为 0 而非 129，向 Unix 惯例靠拢。

**推荐理由**：`git history drop` 把"删掉历史中的某个提交"从 rebase 操作变成一条命令，配合 agent 编码场景下频繁的历史整理，实用价值不小。

## [1993 年 NVIDIA 期权往事：合同写的是四个季度归属，公司按四年执行，三十年后已无法追诉](https://colo.to/nvidia-stock-narrative.html)

**推荐理由**：既是 DirectX 只选三角形如何差点终结 NVIDIA 的一手史料，也是一则关于合同条款和诉讼时效的现实警示。

## [劫持 PS5 的 RTMP 推流：用 DNS 把自己的机器伪装成 Twitch 接收端](https://yashgarg.dev/posts/hijacking-ps5-rtmp-stream/)

索尼逐步锁死了 PS5 的硬件用途：直播只能推到它支持的少数几家服务，蓝牙也只认自家外设。作者想把游戏画面共享到 Discord，买采集卡要花一百多美元，Remote Play 则要求把手柄耳机全部接到接收端且画质不可控。他注意到 PS5 推流用的是 RTMP，而且不硬编码 Twitch 的 IP，每次都走 DNS 解析——那就控制 DNS 返回值，把流引到自己的机器上。第一次尝试直接伪装 `ingest.twitch.tv` 失败了：那其实是个 HTTPS 发现端点，PS5 先问"该用哪个区域的接入服务器"，Twitch 回一个形如 `ap-southeast-1.prod.fi.contribute.live-video.net` 的地址，真正的流才推到那里。文章记录了绕过这层发现机制的完整过程。

**推荐理由**：把封闭主机的既有功能重新引导到自己的设备上，是一个思路干净、成本为零的协议层折腾样本。
