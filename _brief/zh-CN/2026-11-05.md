## [OpenAI 用 Agent 流水线在 Linux 内核里造出 948 个提权漏洞利用，花了 121 万美元](https://openai.com/index/a-thousand-fewer-paths-to-root/)

OpenAI 公布了一次在受控环境里对 Linux 内核的大规模自动化漏洞研究：流水线共产出 2308 条候选发现、动态复现 1724 个漏洞、并写出 948 个可让普通本地用户拿到 root 的提权利用。五个阶段依次是发现、动态验证、可利用性评估、补丁生成和人工复核。Scout agent 先把 4000 万行代码筛到 5034 个审计目标（约 280 万行、占全仓 7%），这一步只花 3426 美元；Analyst agent 在 12 小时内产出候选，花 31.6 万美元；利用阶段最贵，77.6 万美元。十月那轮端到端成本 121.3 万美元，单个成功利用平均 359 美元，而失败尝试平均要 3922 美元——贵了十倍。对照组：kernelCTF 今年至今总共只收录 26 个确认的 0-day 提权。OpenAI 称已按内核社区建议先报送关键漏洞。

**推荐理由**：攻防经济学被改写了。按历史赏金折算这批利用价值 1890 万美元，而生成成本只有 121 万——这个比例一旦稳定，内核维护者面对的报告洪流会是另一个量级。

## [PHP2Shell 的真正教训：AI 把一个搁置两年的"只是崩溃"变成了远程代码执行](https://spectrum.ieee.org/ai-in-cybersecurity-php2shell-vulnerability)

IEEE Spectrum 复盘十月底的 PHP2Shell 漏洞——它波及 NASA、维基百科、白宫以及所有跑 WordPress 和 Drupal 的站点。关键情节是：底层那个越界写 bug 早在 2024 年就报给了 PHP 基金会，但因为只表现为崩溃而被长期搁置。今年由 OpenAI 赞助、安全公司 Calif 独立审计 PHP，研究员借助 AI 工具在两周内把它变成了可在宿主机上执行任意代码的严重漏洞。哥伦比亚大学的 Suman Jana 说这类活"不是火箭科学，只是需要大量极其具体、做起来很痛苦的推理，而 AI 在这件事上做得非常好"。Tolmo 的 Matt Suiche 则概括为"过去四十年人类写的遗留软件正在被集中曝光，是时候还技术债了"。最刺眼的是不对称：找出漏洞两周，四名工程师写补丁用了两个月。约翰霍普金斯的 Matthew Green 更悲观——"要等真出大事，大概 2027 年初，大家才会开始掏钱。"

**推荐理由**：和上一条是同一枚硬币的两面。全世界积压的"低优先级崩溃报告"突然全部变成了待引爆的库存，而修补一侧的产能没有任何同步增长。

## [币安 63 亿美元失窃的完整路径：假面试、Homebrew 投毒，以及被攻陷的内部 AI 工具](https://www.theregister.com/security/2026/11/03/north-korean-fake-job-interview-led-to-63b-binance-heist/5307398)

币安周二发布事件报告，还原了 10 月 29 日那起史上最大加密劫案。攻击始于 6 月：一名工程师下载了被投毒的 Homebrew 安装包，虽被安全团队发现并换机轮转凭证，但"工程师 A 在钱包基础设施团队中的角色已经暴露给攻击者"。9 月，另一名工程师在正规招聘平台上被假"项目总监"接洽，第一轮视频面试中对方主动分享带个人照片和视频的社交账号来建立信任，第二轮假"CEO"让他下载一份夹带恶意代码仓库的"作业"。脚本把 Homebrew 里的 pyenv 替换成恶意版本，终端安全工具未能及时检出。10 月 20 日攻击者借被控机器和一个内部 AI 工具横向移动到两名钱包工程师的电脑，29 日用窃得的容器部署令牌发起盗币。FBI 已归因于朝鲜的 TraderTraitor（Lazarus 关联）。

**推荐理由**：注意那个被一笔带过的细节——内部 AI 工具是横向移动的跳板。Agent 拿到的权限正在成为攻击链里最顺手的一环，而它通常不在威胁模型里。

## [Kimi K3.1 Pro 开权重：2.8T 总参数、104B 激活，Terminal-Bench 4.0 拿下 65.7](https://huggingface.co/moonshotai/Kimi-K3.1-Pro)

月之暗面发布 K3.1 系列首个模型并开放权重。架构是 MoE，总参数 2.8T、每 token 激活 104B、93 层、896 个专家选 16，原生多模态（MoonViT-V2 视觉编码器 401M），上下文 100 万 token。注意力层做了混搭：69 层 KDA 加 24 层 Gated DSA——相比 K3，全注意力的 Gated MLA 层被换成了 DeepSeek 稀疏注意力的门控版本，用于长上下文。权重以 MXFP4 存储、激活 MXFP8，且是量化感知训练而非事后校准。成绩上 Terminal-Bench 4.0 得 65.7，高于 Claude Fable 5.1（57.9）和 GPT-6 Astra（58.2），略低于 Claude Opus 5.5（66.4）；BrowseComp 92.1、HLE-Full 带工具 70.0 均居首；但 Program Bench 只有 31.5，明显落后于闭源对手。

**推荐理由**：开权重模型在 Agent 类基准上贴到了闭源第一梯队，而在纯程序合成上仍有断层。这两个数字放在一起，比任何单项榜首都更能说明差距到底还剩在哪。

## [Anthropic 发布 FlashProve：给大模型推理加上密码学证明，但代价是 70 到 95 倍算力](https://www.anthropic.com/research/provable-inference)

Anthropic 前沿红队联合 EPFL、MIT 等机构公布了推理可证明性的阶段性进展。要解决的问题很实在：用户今天无法验证回复是否真的出自自己选的那个模型，而不是路由服务出于成本偷换的、或被攻击者篡改过的。方案用 zkSNARK——对模型做承诺，再为每次回复生成证明。实测在 Llama 4 Maverick（400B MoE、4bit 量化）上，单张 H100 的出证速度约 110 token/秒，每 1024 token 请求的证明约 19MB，代价是相当于 vLLM 直接推理的 70 到 95 倍 GPU 时间——但比既有开源系统快了几个数量级。证明过程隐藏权重，但不隐藏架构。值得注意的是方法论：优化由 Claude 完成，而 Anthropic 坦言"Claude 擅长优化，但常做出难以评估的决策"，因此用 Lean 形式化语言给顶层安全声明写了可审计的证明。代码、Lean 证明与文档以 Apache 2.0 释出。

**推荐理由**：70 倍开销眼下不实用，但这是"模型身份"第一次有了密码学定义。等到合规要求验证"你跑的到底是哪个模型"时，这条线的成熟度会决定监管能不能落地。

## [C++26 在最终投票中被否决：合约特性引发的分歧，可能让标准推迟甚至回退到 C++23](https://andreasfertig.com/blog/2026/11/cpp26-dis-failed-how-does-cpp-survive/)

Andreas Fertig 解释了 10 月 23 日那次投票的分量：C++26 没能在 DIS 阶段（ISO 标准的倒数第二步）拿到所需的三分之二多数。各国标准化机构的反对意见指向同一处——合约（Contracts）尚未成熟。真正棘手的是流程本身。合约从 2019 年科隆会议被纳入 C++20 又在同次会议被移除算起，经历了 2020 至 2024 年的专门研究组、EWG 多次会议、2026 年 3 月 WG21 以大比例多数通过草案，如今却在终局被 NB 层面推翻。Fertig 指出惯例一向是"只有出现新信息或流程错误时 NB 才投反对"，而他不认为"一篇用旧论据写的新论文"算新信息。ISO 给出的四条出路——改稿重投、退回 CD 阶段、改作技术规范、取消项目——每一条都要求 WG21 内部再次形成多数，而这正是当下缺的东西。最后一条意味着退回 C++23，已进入 C++26 的特性需要有人逐个重新提案，没人跟进的就会丢失。

**推荐理由**：这不是一个特性的技术争论，而是标准化机制的信任危机。一个耗时七年、多轮投票通过的特性能在终点被推翻，意味着 WG21 的流程共识本身出了问题。

## [AMD 预计下季度营收超越英特尔，x86 市场的王座要换人了](https://www.theregister.com/systems/2026/11/04/amd_on_track_to_overtake_intel/5307448)

AMD 周二公布 Q3 财报：营收同比增 45% 至 134 亿美元，其中数据中心部门 85 亿、同比增 97%。更关键的是指引——AMD 预计下季度约 170 亿美元，而英特尔给出的指引是 150 至 160 亿、几乎零增长。如果兑现，这将是历史上第一次由 AMD 成为以 x86 处理器为主业的最大厂商（英特尔总营收仍更高，但那包含代工业务）。苏姿丰在电话会上给 2027 年定了调：全公司增长超 80%，数据中心 CPU 业务翻倍，数据中心 AI 业务"显著超过翻倍"，并称已跨供应链锁定晶圆、基板、先进封装和内存产能。客户端与游戏部门营收下滑 8% 至 37 亿，但拆开看 PC 芯片实际同比增 7%，拖累来自游戏；苏姿丰强调商用占比在上升，大型银行、汽车与医疗企业正批量采用 Ryzen PRO。

**推荐理由**：数据中心 97% 的增速和"锁定内存产能"这句话要连起来读——AMD 拿走的那部分内存，正是上一条消费级 PC 买不起的那部分。

## [OpenAI 收购 Pierre：继自研 Git 后端之后，把代码评审这一层也收进 Codex](https://openai.com/index/openai-to-acquire-pierre/)

OpenAI 宣布收购 Pierre Computer Company——Code Storage 的开发商，也是 Codex 应用里 Trees（文件浏览）和 Diffs（变更查看）两个库的作者。公告直白地给出了动机：随着越来越多工作并行发生，Git 周边的系统必须跟着演化，目标是"从 Agent 创建的第一个分支，到代码部署上线的那一刻"全链路。Pierre 的产品细节相当见功夫：Diffs 的 Edit 模式允许评审者在发现问题的那一行直接修改；最近发布的 Highlights 是一个能跟上开发者打字或 Agent 流式输出速度的语法高亮器。这是同一周内的第二步——此前 OpenAI 刚公开自研 Git 后端 Pando。官方承诺 Pierre 的开源项目保持开源并继续贡献，Code Storage 现有客户可继续使用，交易尚待监管批准。

## [Ripple-65B：3200 万美元从零训出一个稠密模型，TerminalBench 2.1 打败十倍大的开权重对手](https://www.ricursive.com/ripple)

芯片设计公司 Ricursive Intelligence 开源了 Ripple-65B Preview——驱动其 AI 芯片设计平台的自研模型的通用版本，12 万亿 token 预训练，支持 100 万上下文。TerminalBench 2.1 得 80.52，超过 Reflection Beam 501B（80.1）、Meta Muse Spark Open 816B（76.4）、Nvidia Nemotron 3 Ultra 550B（56.4）。但最值得注意的是成本：全部 R&D 从零算起只花了 3200 万美元，约为前任开权重 SOTA 的十分之一。几个反潮流的工程选择：坚持稠密 Transformer 而非 MoE，理由是降低训练与服务的基础设施复杂度，结果在无自定义 kernel、无量化、简单分片的条件下全程维持 40% MFU；窄而深的形制（d_model 5120、80 层）、超配注意力头、提高滑窗与全局层比例。RL 阶段只用了 140 万次 rollout 就爬到 80.5，比 Reflection Beam 少约 70 倍。模型梯度实验从 Olmo 3 的 ladder 起步，逐版叠加后在 4B 规模上把代码方向的计算效率提升至多 16 倍。参数规模小也让它能在 DGX Spark 这类高算力、低带宽的本地设备上跑。

**推荐理由**：和上周 Mistral Large 4 的 415 万 GPU 小时并排看。两条路线——堆规模与抠配方——同时交卷，而后者的性价比数字很难被忽视。

## [Nvidia 等机构论文：别买长上下文了，频繁压缩就够用](https://arxiv.org/abs/2611.05306)

Peter Belcak、Pavlo Molchanov 等 Nvidia 研究者提出一个直接挑战行业共识的结论。出发点是成本的物理事实：靠后的 token 比靠前的贵，在前沿开权重模型上这个差距可达 7 倍；他们在 DGX Spark 上实测了多个开源模型的生成延迟、吞吐和显存随输入长度的变化曲线。做法是频繁压缩（compaction），在一系列长程任务和长输入任务上，前沿模型在始终保持短上下文的条件下几乎不损失准确率。更激进的是，他们证明即便限制到"每个上下文最多执行一个动作"，模型在长程软件工程任务上的表现也不会崩塌，并据此提出语义状态空间模型（SSSM）的概念。结论直指需求本身：我们可能并不需要长上下文语言模型。

**推荐理由**：这和昨天 Revolut 工程师那句"长上下文是个骗局"在同一周从两端得到印证——一端是 2000 人团队的实测账单，一端是受控实验。百万上下文的营销价值，可能远高于它的使用价值。

## [Synaptics 用专利威胁逼停了社区的开源 DisplayLink 驱动](https://www.phoronix.com/news/Synaptics-Blocks-Vino-Driver)

今年早些时候出现过一个叫 Vino 的实验性开源 Linux 驱动，面向现代 DisplayLink 硬件，由社区以净室逆向方式开发、部分借助 AI、用 Rust 编写。Phoronix 发现它已经消失——有读者在 LKML 邮件列表上贴出了相关往来：Synaptics 以侵犯其专利为由，向开发者发出了停止侵害通知（cease and desist），GitHub 仓库随即下架。结果是短期内 Linux 不会有上游的开源 DisplayLink 驱动。讽刺之处在于对比：USB2 时代最早的 DisplayLink 硬件在 Linux 上工作良好，甚至有过开源驱动支持；而厂商对自家最新的 USB 显示 IP，看来打算确保不存在任何开源驱动。

**推荐理由**：净室逆向在法律上向来是安全区，而专利不吃这一套——它不问你怎么写出来的，只问功能是否落入权利要求。这是一条绕不过去的边界，值得每个做硬件兼容的人记住。

## [为了破解 2003 年的 T-Mobile Sidekick，有人用 220 个核分解了一把 512 位 RSA 密钥](https://x86.cx/blog/redanger)

一篇漂亮的考古作业。Danger Hiptop（即 T-Mobile Sidekick）2002 年上市，自带全键盘、内建 AIM 与雅虎通、支持推送通知——而且联系人、短信、照片、设置全在 Danger 的服务器上，是"云"这个词流行之前的云设备。微软 2008 年收购 Danger，2009 年一次灾难性数据丢失抹掉了用户的全部个人数据，服务 2011 年彻底关闭。作者想在真机上跑自己的代码，但 DangerOS 只运行 Danger 或运营商签名的软件，而发放开发者密钥的网站 2010 年已随公司一起关门。他从 archive.org 上的刷机工具里翻出完整出厂固件镜像，扫出几十张证书，发现其中"Danger Developer Program"那张自签根证书只有 512 位 RSA——而 512 位在 1999 年 RSA-155 被分解后就不再安全，Danger 却在四年后签发了它。用 CADO-NFS 跑通用数域筛法，七台机器 220 核 436 线程，8.5 小时、约 1175 核时后分解成功。

**推荐理由**：二十三年前被认为"够用"的密钥强度，今天一个晚上就能破。顺带一提，文中那句对照很扎心——Google 正在推进开发者验证，未注册开发者的应用将只能通过 adb 或深埋的高级选项安装。
