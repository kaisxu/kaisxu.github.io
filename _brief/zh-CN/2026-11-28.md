**推荐理由**：军用云管理层汇聚多种敏感业务，事件影响可能远超单一应用；重点观察权限隔离、恢复能力及后续调查，而非先猜攻击归属。

vSFT 让监督模型分析 Agent 的失败轨迹，再由预先训练的超网络把语言反馈转换成低秩权重更新，而不只是把反思追加到提示词。论文用 Qwen3-4B 在家庭任务和模拟购物环境中实验，报告优于多种上下文反思及强化学习基线。公开答辩也涉及参考任务、相同尝试次数和训练成本的争议；作者补充了比较，但这些结果仍不能直接证明真实开放环境中的收益。

## [Sentinel 新项目：用终端记录和 Git diff 检查编码 Agent 是否言行一致](https://github.com/run-llama/sentinel)

*项目公开：11 月 27 日 19:58 UTC；随后提交多模型切换功能，来自 HN 线索。*

新开源项目 Sentinel 面向 macOS Terminal，读取编码 Agent 的终端进展，并结合工作目录的 Git 状态、差异和近期提交进行模型审查。它尝试区分停滞、误解、忽略指令及破坏性修改，并生成供用户转交的提醒；支持云端模型，也支持本地 Ollama。当前仍是早期工具，没有独立准确率验证，给行为贴上“破坏”标签也不等于证明模型具有恶意。

**推荐理由**：与其只相信 Agent 的完成声明，不如对照真实文件变化；项目提供可检查的实现思路，但第二个模型的判断同样需要人来复核。

## [手机浏览器也能成为 Kubernetes 节点：Tabernetes 把 Linux 工作负载带进标签页](https://fzakaria.com/2026/11/27/your-phone-is-a-kubernetes-node)

*作者新文：11 月 27 日 18:00 UTC；来自 HN 线索。*

Farid Zakaria 展示 Tabernetes：手机打开网页后，浏览器内启动 Linux，服务器端代理为标签页扮演 kubelet，让真实的 k3s 集群调度工作负载。浏览器提供 CPU 和内存，镜像与数据卷留在服务器，因此并不是把完整集群都搬进手机。作者明确将其定位为实验，不建议用于生产；它展示的是浏览器计算与云端状态分离的新组合，而非手机替代数据中心。

**推荐理由**：这是少见的便携计算玩法，把随身设备接到现有调度体系；理解其计算、存储和控制面的分工，比单看“手机跑容器”的演示更有趣。
