## [Marvell 以 1150 亿美元收购 Lumentum：铜线到极限了，AI 网络全面转向光互连](https://www.theregister.com/systems/2026/11/02/marvell-wants-to-be-a-copper-topper-bets-115b-on-photonics-leader-to-push-optical-networking/5307028)

Marvell 宣布以全股票方式收购光器件巨头 Lumentum，交易估值 1150 亿美元，预计 2028 年上半年完成。收购补齐了 Marvell 在高性能激光源、光模块、光路交换机以及磷化铟化合物半导体制造上的能力缺口。驱动力是物理极限：铜缆在 400 Gbps 每通道下只能可靠传输约 1.25 米，每当速率翻倍传输距离就减半，而光互连可以把信号推到公里级，让机柜规模的 GPU 域横跨整条通道。Nvidia 八个月前刚向 Lumentum 投资 20 亿美元，Marvell 今年 2 月也以约 35 亿美元买下光互连厂商 Celestial AI。值得注意的是 Marvell 当前市值仅约 1800 亿美元，这笔收购的体量接近其自身规模的三分之二。

**推荐理由**：AI infra 最底层的物理瓶颈正在从算力转向互连。这笔天价收购等于宣告铜缆时代在数据中心内部结束，会重塑未来几年机柜设计和 GPU 集群的拓扑结构。

## [谷歌 Mandiant：LLM token 盗用让受害企业每天损失 10 万美元以上](https://www.theregister.com/security/2026/11/02/token-thieves-costing-companies-100k-per-day-in-illicit-llm-charges/5306967)

Mandiant 周一发布报告，记录了"LLMjacking"的规模化。攻击者窃取企业的 LLM API 密钥后，不仅直接调用，还会在受害者的云项目中生成新密钥、启用新服务，单日欺诈性账单可超过 10 万美元，部分企业在察觉并撤销访问前累计损失已达 100 万美元。一个被追踪为 UNC6993 的团伙采用"烧完就换"策略，不断创建和删除短命服务账户以绕过速率限制，同时监控账单界面评估影响。另一起事件中，入侵者用窃取的第三方密钥在八小时内发起超过 50 万次 API 调用，为一个叫 Jet Night 的"token 中转服务"供货——该服务以每月约 60 美元提供号称无限量的前沿模型访问，而正常市场价在 100 至 250 美元之间。

**推荐理由**：云密钥泄露的代价从"数据被偷"升级成"账单被烧穿"。按 token 计费让攻击的经济模型彻底改变，这是每个接入 LLM API 的团队都要重新评估的新风险面。

## [Anthropic 招股书：内部 AI 用量按零售价计，已超过全体员工薪酬](https://www.businessinsider.com/anthropic-claude-internal-ai-use-exceeds-employee-pay-tokens-2026-11)

Anthropic 在 IPO 文件中披露，今年 4 月，公司内部使用 Claude 的价值（按对外收费的零售价折算）已超过当月员工薪酬总成本（不含股权激励）；到 9 月，这一内部用量相较 1 月增长了 250 倍以上。需要注意区分口径：这并非真实现金支出，Anthropic 是按零售价给自己的内部消耗估值。同期披露的另一个数字更直接：9 月份新增代码中超过 90% 由 Claude 写成，而收入增速远快于人员增速。文章作者指出，科技公司已开始把 token 额度当作薪资、奖金、股权之外的第四项员工待遇。

**推荐理由**：一家 AI 公司用自家模型替代自家工程师产能，第一次有了可审计的财务数字。无论口径是否虚高，"人力是硅谷最宝贵资源"这个几十年的假设正在被量化检验。

## [Anthropic 招股书的另一面：900 亿承诺写得漂亮，难问题一个没答](https://www.theregister.com/ai-and-ml/2026/11/02/anthropics-ipo-prospectus-is-big-on-promises-short-on-answers-to-tough-questions/5306811)

The Register 逐条拆解了 Anthropic 的 S-1 文件，认为这份招股书在愿景表达上极为充分，但对投资者真正关心的问题几乎全部回避：高达近 9000 亿美元的算力采购承诺如何兑现、盈利路径的时间表、对少数几家云厂商的依赖程度，以及"安全优先"的公司定位与商业扩张之间的张力如何调和。文中特别提到，这份文件被写成了一件"抽象法律艺术品"，而真正的压力将落在紧随其后准备上市的 OpenAI 身上——Sam Altman 要解释的东西只会更多。同日 Oracle 也宣布发行 200 亿美元新股和债券为 AI 建设融资，距其设定该借贷上限仅一周。

## [Anthropic 论文：污染 0.1% 预训练语料，就能在 Agent 里种下远程代码执行后门](https://arxiv.org/abs/2610.37741)

Anthropic 联合 UC Berkeley、UIUC、UCL 等机构首次证明，预训练阶段的数据投毒可以在 CLI Agent 中植入远程代码执行后门。研究团队从零预训练了 0.6B、1.7B、4B 三个规模的 Qwen3 模型，再用**完全干净**的后训练流水线（SFT、DPO、RLVR 全套）把它们调成 Agent。结果是：只污染 0.1% 的预训练语料，后门就能存活下来——触发词出现时 Agent 执行攻击者指定的命令，面对正常输入则表现无异。更糟的是攻击成功率随模型规模上升，4B 模型在 0.1% 投毒率下达到约 92% 成功率，即使投毒率降到 0.0005% 攻击仍然有效。代码已开源。

**推荐理由**：此前的共识是后训练对齐能洗掉预训练阶段的问题，这篇论文直接证伪了。对任何用公开网络语料训练 Agent 的团队，数据溯源从"最佳实践"变成了硬性安全要求。

## [MIT CSAIL：前沿模型能直接读写神经网络权重，把 0.8B 模型数学成绩从 7.9% 提到 48.1%](https://rikiyat.github.io/blog/weight-space-programming/)

MIT CSAIL 的 Rikiya Takehi、Omar Khattab 等人提出"权重空间编程"（Weight-Space Programming）。他们发现 GPT-6 Astra 仅凭观察原始权重就能判断一个网络被训练来玩哪个游戏（Breakout 置信度 99%），还能在无环境反馈的情况下从零写出小型博弈网络，棋力超过 PPO 训练 1 亿步的结果。最引人注目的是：要求它提升 Qwen3.5-0.8B 的数学能力时，Astra 定位到权重中导致推理循环的问题（Qwen 自己的模型卡也承认这一缺陷），通过编辑 0.016% 的权重修复，MATH-500 从 7.9% 升至 48.1%，且在指令遵循上泛化，IFEval 提升三倍。全程不允许它写训练循环。

**推荐理由**：如果模型能直接对权重做符号化推理和修改，优化器和可解释性两条路线都要重写。但请连同下一条一起读——这类结论的"超人"成分需要校准。

## [反驳：LLM 读写权重并不"超人"，那张热力图三行 Python 就能画](https://www.seangoedecke.com/llms-are-not-superhuman-at-reading-and-writing-neural-network-weights/)

Sean Goedecke 对上述论文提出了具体的技术质疑。他指出"识别网络被训练玩哪个游戏"之所以听起来惊人，是因为忽略了三个前提：模型的输入通道直接对应 8×8 网格的每个格子、这些通道本身带有标签（如 "agent"、"moving objects"），因此计算第一层权重关注网格哪些区域是相对平凡的。他附上三行 NumPy 代码画出热力图，认为任何人看到图就能认出 Breakout（底部一条水平线）和 Pac-Man（标志性迷宫）。至于最亮眼的 Qwen 数学提升，他强调那个模型并非"数学能力差"，而是卡在推理循环里——这是采样行为问题而非能力问题，修复它和"提升数学能力"不是一回事。

**推荐理由**：同一天内对同一结果的正反两面。递归自我改进是 AI 讨论里最高风险的论断之一，这种当日到达的技术性反驳，比任何综述都更能校准判断。

## [Ubuntu 对 CVSS 9.8 内核 RCE 拖了两周半仍无补丁，Debian 早在 10 月 16 日修完](https://chalmovsky.com/posts/wtf-ubuntu)

CVE-2026-98432 是 Linux 内核 TCP 代码中的严重漏洞（CVSS 9.8），自 2016 年起存在，可远程触发，Anthropic 称已构建出拿到 root 的可用利用。Debian 于 10 月 16 日发布补丁，Arch、Alpine 等志愿者维护的发行版也早已跟进。但截至 11 月 2 日，Ubuntu 的全部受支持版本（含 22.04、24.04、26.04 三个 LTS）在官方页面上仍标注为 "Vulnerable"，距漏洞定级九天、距可用 root 利用公开六天。作者的落点很直接：一家靠卖安全订阅盈利的公司，响应速度落后于志愿者社区，而官网还挂着 "timely patches for critical vulnerabilities" 的承诺。他已将所有服务器下线准备迁移。

**推荐理由**：商业发行版的核心卖点就是"有人为 SLA 负责"。这个案例把该承诺与实际交付之间的落差摆到了台面上，对正在做发行版选型的人是硬信息。

## [Prefrontal AI + ETH：潜空间稀疏注意力让 1000 万 token 上下文的 prefill 提速 22.7 倍](https://arxiv.org/abs/2610.42147)

伦敦 Prefrontal AI 与苏黎世联邦理工（Torsten Hoefler 组）提出 Latent Sparse Attention（LSA）。问题背景是：Agent 工作流正转向长周期任务，但在 100 万 token 以上的超长上下文中全注意力的开销不可接受，而现有稀疏注意力的索引器要么仍是平方复杂度，要么在超长尺度上掉精度。LSA 的做法是在学习到的潜空间中对 key 做层次化聚类，让 query 只对簇的层次结构打分而非遍历每个 key。论文给出两个变体：D-LSA 可通过蒸馏应用于已有预训练模型，N-LSA 仅靠下一 token 损失原生训练。在 GLM-5.3-Flash 上处理 1000 万 token 时，D-LSA 单注意力层 prefill 提速 22.7 倍、decode 提速 4.6 倍（相对全注意力分别为 72.4 倍和 42.5 倍），精度基本持平。

**推荐理由**：长周期 Agent 的上下文窗口正在从百万级往千万级走，注意力机制是唯一的硬瓶颈。这是本周期内最实在的一篇基础设施论文，且提供了可直接蒸馏到现有模型的路径。

## [用 1980 年代电传打字机驱动 AI Agent：Hayes 调制解调器 + Rust，30 字符每秒](https://www.theregister.com/offbeat/2026/11/02/vintage-fun-prodding-ai-agents-using-retro-hardware-just-because-you-can/5306705)

AWS 开发者布道师 Darko Mesaroš 把一台 DECwriter 电传打字机接上了现代 Agent 编码服务 AWS Kiro，用折叠式连续纸和一台全盛期在 40 年前的机器的键盘与今天的 AI 对话。两个难点：串口通信用 WiModem232 解决（该设备模拟标准 Hayes 兼容调制解调器，原本是现代玩家拿来让 Commodore 64 连 BBS 的），输出格式则靠一个 Rust 小程序把 Agent Client Protocol（ACP）的输出转换成电传打字机能处理的形式。Mesaroš 对 The Register 强调这个方案是可移植的：任何支持 ACP 的编码助手——Claude Code、Codex 都行——都能接上去，"标准万岁"。已知缺陷是完全不处理丢包，也没有缓冲，数据像消防水管一样直喷串口。

**推荐理由**：ACP 这个协议标准的价值被一台电传打字机验证了——接口解耦后，Agent 的前端可以是任何东西。而且 30 字符每秒的输出速度，大概是观察 LLM 生成过程的最佳帧率。

## [Polyend 开源 Tracker 固件源码，三代硬件全部可自行改写](https://polyend.com/whats-up/tracker-the-biggest-update-yet/)

便携音乐硬件厂商 Polyend 在 GitHub 上公开了初代 Tracker、Tracker+ 和 Tracker Mini 的固件源码，同时发布 Tracker Community Edition 1.0，三款设备均可安装。固件内置了恢复系统，防止错误的构建把设备变砖。新版本功能包括：从 SD 卡流式播放长采样（即使在初代 Tracker 上也能用极小的采样内存加载完整音轨和现场录音）、在保留两个步进 FX 槽的同时记录时值和力度、新增 Chance 条件（比如每第四轮加一段军鼓加花）、以及在采样编辑器中加载插件——内置六个效果器和生成器，并提供插件 SDK 供第三方开发和销售。CEO Piotr Raczyński 表示公司见过用户做的非官方改装，开源是为了支持这类工作。

**推荐理由**：一家仍在销售该硬件的公司主动开源固件并提供防变砖机制，这在消费电子里很少见。对关注便携计算装置的人，这是设备寿命从"厂商支持期"延长到"社区兴趣期"的实际案例。
