## [五角大楼正式停用 Anthropic 全部产品](https://www.bbc.co.uk/news/articles/c5j9x9pr0240o)

美国国防部一名官员 10 月 5 日向 BBC 确认，国防部"已停止使用 Anthropic 产品"。今年 2 月国防部长赫格塞思把 Anthropic 列为"国家安全供应链风险"——这条法律通常只用于来自敌对国家的企业——起因是国防部要求 Anthropic 撤掉 Claude 的安全护栏、交出不受限制的军事使用权，而 Anthropic 以大规模监控和自主武器为由拒绝。多位知情人士称，直到上周 Claude 仍在该部门用于研究、情报分析乃至对伊朗的军事行动，被视为处理海量信息的关键工具。Anthropic 已起诉特朗普政府要求撤销该认定，8 月 28 日一名法官已裁定政府的报复行为违法。

**推荐理由**：一家 AI 公司因拒绝交出安全控制权而被国家机器整体驱逐，这是模型提供方与政府权力关系的第一个明确判例。

## [高通向华为支付专利费，交叉许可涉及 LogicFolding，总额超 69 亿美元](https://soyacincau.com/2026/10/05/huawei-qualcomm-cross-licence-patent-deal-5g-ai-logic-folding/)

## [Anthropic IPO 招股书泄露：三分之一篇幅在讲生存风险，去年亏 80 亿美元](https://www.theregister.com/ai-and-ml/2026/10/05/anthropic-says-its-ipo-could-herald-the-end-of-the-world-as-we-know-it/5300908)

英国《金融时报》独家拿到的 Anthropic IPO 招股书显示，文件中约三分之一的内容在论述 AI 的生存性风险。财务侧则是另一幅图景：46 亿美元营收对应约 80 亿美元亏损，且公司计划在未来数年投入约 5000 亿美元用于云计算采购。The Register 的播客节目直言，用"我们的技术可能毁灭世界"来向投资人推销自己是一种奇特的叙事策略，并怀疑这套末日话术的真实作用是把注意力从盈利路径的缺失上引开。

**推荐理由**：把"安全论述"写进招股书，意味着它已经成为一种可估值的资产而非纯粹的伦理立场。这是 AI 泡沫叙事的新形态。

## [Reflection 发布 Beam：5010 亿参数开放权重模型，用 1.05 万张 GB300 跑了四周 RL](https://reflection.ai/blog/introducing-beam)

Reflection 推出首个开放权重模型 Beam，稀疏 MoE 架构，总参数 5010 亿、激活 230 亿，面向编程、推理与智能体负载。预训练用了 23.8 万亿 token；强化学习阶段在 1.05 万张 NVIDIA GB300 上训练四周，生成超过 1 亿条 rollout，最大上下文 25.6 万 token。官方称 Beam 在编程与智能体任务上可与 GLM-5.2 竞争、接近 Qwen 3.8-Max，而在高级推理基准上达到 GLM-5.2 水平的同时推理算力少 3–4 倍。权重、技术报告与模型卡将于本月晚些时候发布。

**推荐理由**：西方阵营的开放权重前沿被中国模型甩开已有一段时间，Beam 选择不拼绝对能力而拼单 token 推理效率，是一条务实的差异化路线。

## [丹麦中央人口登记库 880 万人信息遭非授权访问](https://www.bleepingcomputer.com/news/security/denmark-population-registry-data-breach-affects-88-million-people/)

丹麦确认其中央人口登记系统 CPR 发生大规模数据泄露，约 880 万人的姓名、地址与 CPR 身份号码被非授权方获取——这个数字超过丹麦全国人口，因为登记库同时包含已故者和曾在丹麦居住的人。登记库本身并未被攻破：一家丹麦私营公司拥有合法查询权限，该权限在 2026 年 9 月期间被非授权方滥用，用于批量检索记录。丹麦数字化部已就此展开调查。

**推荐理由**：攻击面不在系统本身而在被授权的第三方。身份号码体系一旦全民化，任何一个合法接口的失守都等同于全国库被抄走。

## [OpenAI 开始在 ChatGPT 图像生成环节插入视觉广告](https://www.theregister.com/ai-and-ml/2026/10/05/openai-to-flood-your-eyeballs-with-visual-ads/5301152)

## [Altman 投资的 Volantis：用光子中介层给加速器挂 10TB 内存、240TB/s 带宽](https://www.theregister.com/systems/2026/10/05/altman-backed-volantis-reveals-plan-to-vault-the-memory-wall-by-baking-photonics-into-ai-accelerators/5300959)

由 Sam Altman 投资、2022 年成立于旧金山的 AI 芯片初创公司 Volantis 公开了其技术路线：用光子中介层（photonic interposer）在不牺牲容量的前提下大幅提升内存带宽。公司称可以在单个超大封装上集成超过 10TB 内存、速度高达 240TB/s。与此前同类公司多以 IP 授权为业不同，Volantis 这次做的是完整的 AI 加速器而非仅出售光互连 IP。

**推荐理由**：大模型推理的瓶颈早已从算力转向内存墙，而 HBM 正在涨价和缺货。把光互连做进封装内部是少数几条可能绕开它的路。

## [一队 Claude Opus 5.5 智能体找出两种候选室温磁性半导体](https://www.vals.ai/blogs/room-temperature-magnetic-semiconductors)

vals.ai 公布了由一组 Claude Opus 5.5 智能体参与完成的材料研究：目标是找到净磁矩为零、却仍能按自旋给电子分类的材料，即所谓 Luttinger 补偿（LC）磁体——这类材料的上下自旋原子处在不等价环境中，因而能在保留带隙的同时把自旋按能量分开，是下一代 MRAM 等自旋电子存储的理想衬底。智能体用标准量子力学方法模拟各候选晶体，最终给出两个候选：一个是新设计的化合物，另一个是 1999 年就已合成、但此前未被认识到具备该性质的材料。团队公开了全部计算过程、代码和已知的局限清单。

**推荐理由**：难得地把完整计算和"已知缺陷"一并放出，而不是只发结论。AI 参与科学发现的可信度，取决于的正是这种可复核性。

## [Dust：第一个在预训练 Transformer 上能与反向传播竞争的零阶方法](https://qlabs.sh/research/dust)

qLabs 提出 Dust，对激活空间做节点扰动，并且在每个 token 上独立扰动——于是每个 token 都成为一个"虚拟种群成员"，一次前向传播就把整个种群评估完毕。在大种群（即算力充裕）设定下，Dust 逼近反向传播，部分设置下甚至超过它。相比权重空间进化策略，Dust 的效率高出数个量级：据外推，从 100 万 token 起比当前最优 ES 方法 EGGROLL 的 Transformer 实现高约 10³–10⁴ 倍。与"零阶方法无法扩展到大网络"的普遍认知相反，他们发现更大的模型种群效率更高：2.43 亿参数模型在多数种群规模下胜过小 120 倍的模型。

**推荐理由**：架构、优化器和硬件都是围绕可微分性共同演化出来的。如果搜索在算力充裕时能追平梯度，这套协同演化的前提就需要重估。

## [mold 3.0 发布：高速链接器用 Rust 完整重写](https://github.com/rui314/mold/releases/tag/v3.0.0)

mold 3.0.0 是从 C++ 重写为 Rust 后的首个版本，2.42.1 为 C++ 版的最后一版。作者把它定位为 2.42.1 的直接替代品：命令行选项、支持的目标架构、输出结果均保持一致，链接性能持平；兼容性通过在全部目标架构上跑测试套件、跨大量真实负载比对输出、并完整构建 Gentoo 全部软件包来验证，未发现回归。改用 Rust 的直接收益是面对损坏输入文件更安全——C++ 版可能越界读内存并段错误，新版这些读取都带边界检查，会在出错处 panic。构建系统从 CMake 换成 Cargo，需要 Rust 1.95+，并移除了对 oneTBB 的依赖。mold 3.x 的目标是补齐与 GNU ld 的剩余兼容差距（尤其是链接脚本），为成为 Linux 发行版默认链接器铺路。

**推荐理由**：一次把性能关键的成熟 C++ 项目整体重写到 Rust 而性能不退、且用 Gentoo 全量构建来证明，这是 Rust 重写讨论里罕见的可信样本。

## [Cloudflare 推出 Web Search API，让智能体直接接入实时搜索](https://developers.cloudflare.com/changelog/post/2026-10-02-introducing-web-search-api/)

Cloudflare 的 Web Search API 进入 beta，让 AI 智能体和应用能检索互联网并把回答锚定在实时信息上，而不是猜 URL 或受限于模型训练截止日期。上线即支持三家搜索供应商：Ceramic.ai、Exa 和 Linkup，三家对经 Cloudflare 发出的请求都支持零数据留存（Zero Data Retention），且都承诺遵守 Cloudflare 的可验证爬虫标准。该 API 走 AI Gateway，搜索请求会出现在网关日志中，按各供应商的 API 标价计入 AI Gateway 额度、不加价，也可以自带供应商 API key。

**推荐理由**：把"检索"做成一层可审计、可计费、带爬虫合规承诺的网关，是对当前智能体野蛮抓取的一种基础设施层回应。

## [GrapheneOS：Pixel 11 砍掉内存标记，可能被直接跳过不予支持](https://discuss.grapheneos.org/d/41564-pixel-11-doesnt-yet-meet-the-grapheneos-security-standards-and-may-be-skipped)

GrapheneOS 团队花一周完成了 Pixel 11 的部分移植，但因软件、固件乃至硬件层面都缺乏 ARM 硬件内存标记（MTE）支持而无法收尾，并判断"谷歌为省钱砍掉了一项重要安全特性"。MTE 自 Pixel 8（2023 年 10 月）起可用，GrapheneOS 把它用在包括内核和每个基础系统进程在内的整个系统上，能大幅削弱绝大多数远程漏洞利用。对照组是苹果：iPhone 17 的 Memory Integrity Enforcement 始终开启，在内核与大部分用户态以最安全模式使用 MTE。团队同时指出 Pixel 11 并非全无进步（后量子安全验证启动 ML-DSA、以 AOSP IMS 替换三星 Shannon IMS、Titan M3），但认为"砍掉 MTE 毁了这些"。

**推荐理由**：MTE 是目前对内存安全漏洞最有效的硬件缓解之一。一款旗舰机把它拿掉而舆论几乎无声，说明安全特性在消费端仍缺乏定价能力。

## [JIL：给请求加个对抗后缀，就能在 LLM 调度队列里插队](https://arxiv.org/abs/2610.03430)

佛罗里达州立大学、MIT 与特拉维夫大学的工作。当前 LLM 服务普遍采用基于预测输出长度的调度策略（如最短作业优先），但输出长度生成前未知，只能依赖轻量探针预测。JIL 针对这一预测信号发起攻击：以 TRAIL 为案例，优化出一个对抗性后缀，使长度探针严重低估该请求的输出长度，从而骗取更高优先级。在两个数据集、四个模型、多种请求画像与部署配置下评测，JIL 可使预测输出长度最多降低 83.4%，对抗请求在端到端服务中平均最快可提前 1.53 倍完成。

**推荐理由**：调度器把模型的预测当成可信输入，而这个输入由用户可控的文本生成。多租户推理服务里，这就是一条可被直接利用的不公平通道。

## [Borland Turbo BASIC：那个把编译器装进 IDE 的年代](https://dosdays.co.uk/topics/Software/borland_turbo_basic.php)

Turbo BASIC 的前身是 Bob Zale 为 CP/M 写的 BASIC/Z，号称第一个交互式编译器；1987 年 Borland 买下它并移植到 MS-DOS，只卖了两年就停产，Zale 随后买回版权，以 PowerBASIC 之名延续。它相对 GWBASIC 的关键优势有两点：一是真正的编译器，摆脱了 GWBASIC 的 64KB 源文件上限，程序大小只受可用内存限制；二是带 IDE——在当时编译器被视为专业工具，常规做法是用文本编辑器写代码、再在命令行调编译器和链接器，而 Borland 把编辑、配置编译选项、内存内运行或输出 .EXE 全部收进一个界面。Borland 仅发布了 1.0 与修 bug 的 1.1 两个版本，同年还配套推出了一系列 Turbo Toolbox。

**推荐理由**：今天"编辑—编译—运行"是开发的默认形态，而它成为默认的那一刻正发生在 Borland 这批产品上。顺带还有 Borland 全盛期园区的旧照。
