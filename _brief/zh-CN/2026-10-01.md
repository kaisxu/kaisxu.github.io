## [Google 发布 Gemini 4 Argon：输出上限从 6.4 万暴涨到 100 万 token，且对可信防御方不加网络安全护栏](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/)

Google 推出新一代前沿模型 Gemini 4 Argon，先通过 Fairwind 计划向一批可信网络防御方分批放量，再逐步开放给开发者与企业。定价为每百万输入 token 2 美元、输出 10 美元，缓存输入打 5 折之后的 5%。最显著的变化是输出 token 上限从此前的 64K 提升到 100 万，官方称这让模型能在单次轨迹里"想得更深"。基准方面，Argon 在衡量真实长周期软件工程任务的 DeepSWE v1.1 上拿到 77.9%，在按美国 GDP 贡献加权的 Vals Index 上居首，Zapier 的 AutomationBench 得 51.3% 排名第一，长视频理解 LVBench 91.7%。争议点在于：Google 表示会对内部团队和可信防御方**不加网络安全护栏**地发布 Argon，以释放其自主发现、验证并修补漏洞的完整能力。

**推荐理由**：百万 token 输出上限是架构级的变化，不是跑分微调；而"对特定群体去掉安全护栏"开了一个前沿实验室此前不敢碰的先例。

## [六家前沿实验室签署《白宫超级智能协定》：不具约束力，规则由签字方自己定](https://www.theregister.com/ai-and-ml/2026/09/30/trump-administration-gets-big-tech-to-sign-weak-non-binding-ai-regulations/5299955)

贝恩公司《2026 全球科技报告》测算，AI 行业到 2031 年必须产生每年 6 万亿美元的收入，才能持续为满足预期需求所需的基础设施融资。推算路径是：微软、Google、亚马逊、Meta、甲骨文五家超大规模厂商 2026 全年资本支出可能达 7800 亿美元，接近三年前的五倍；到 2031 年年度 AI 基建支出可达 1.5 万亿美元（Omdia 独立预测为 1.6 万亿）；按资本支出约占行业收入 25% 折算，即得 6 万亿。问题在于，贝恩估计现有 AI 应用（消费订阅与广告、企业软件开发、销售、客服、IT 运维）合计只能贡献 1.2 万亿到 1.8 万亿，缺口高达 4.2 万亿。补口的候选项包括替代搜索引擎并植入广告（1000 亿–2000 亿）、自动驾驶与工业自动化（约 4000 亿）、以及含仿真、数字孪生和机器人的"物理 AI"（最多 9000 亿）——加起来仍远不够。

**推荐理由**：把"AI 泡沫"之争从情绪拉回到可核算的资产负债表上：缺口有多大、靠什么填，一目了然。

## [16 岁研究者攻破微软内部分析平台 Titan：JWT 不验签名，可触及 17.3 万亿行数据](https://www.theregister.com/security/2026/09/30/16-year-old-researcher-found-a-microsoft-bug-got-admin-access-to-databases-with-173-trillion-rows/5300240)

一名代号 Faav 的 16 岁安全研究者，借助自己编写的 AI hackbot "Antares"，在微软内部分析平台 Titan 中发现认证缺陷，获得管理员权限、可在无有效凭据下提交 SQL 查询，理论上可触及约 17.3 万亿行存储数据。Titan 的 Web 界面仅限微软员工访问，但 Faav 发现可通过一台 Azure 云服务主机访问其 API。根因极其基础：**Titan 校验了 JWT 的全部内容（租户、受众、应用 ID、用户），唯独从不验证签名**。8 月 25 日 Antares 找到公开 API，经过十天认证报错的碰壁，9 月 5 日凌晨他把一个未签名 token 的 UPN 从邮箱格式改成 `admin`，Titan 将其解析为本地用户名、对应到 ID 1（管理员角色），随即放行 SQL。拿到的元数据库包含 24,569 个仪表盘、425,891 张图表、27,347 个数据集定义，以及员工职位、部门和汇报关系。微软已封堵 API，支付 5000 美元赏金。

**推荐理由**：作者本人的总结值得每个写认证代码的人（和每个 coding agent）抄一遍：验签名比其余所有访问控制逻辑加起来都重要。

## [Spectre 再度归来：BTR 攻击利用 JIT 代码缓存中的陈旧分支目标，实现"推测性 use-after-free"](https://www.theregister.com/security/2026/09/30/spectre-bug-is-back-this-time-to-haunt-jit-engines/5299937)

荷兰阿姆斯特丹自由大学与意大利圣安娜高等学校的研究者提出名为 Branch Target Reuse（BTR）的新型 Spectre v2 攻击，是首个针对 JIT 编译器的实用**原地**攻击（攻击局限于受害者自身的分支，而非依赖另一分支的推测）。核心洞察是：现代 CPU 在自修改代码后会恢复架构层面的代码一致性，但**不一定会作废陈旧的间接分支预测条目**。在 JIT 引擎中，这些陈旧的分支目标可以比原始代码活得更久，等代码缓存被重新填充时又被复用，从而形成一个推测性的 execute-after-free 原语。受影响的 JIT 引擎包括 Linux cBPF、Oracle GraalVM 和 Mozilla SpiderMonkey。研究者构造了两个针对 Intel 平台 Linux 内核的 PoC，即便开启 cBPF 的常量绑定防御，仍能读出 root 口令哈希；泄漏速率在 Raptor Cove 上约 5.7 KB/秒。该攻击可绕过 FineIBT 等软件防御。Linux 内核与 Oracle 已发布缓解，分配 CVE-2026-64507 和 CVE-2026-64508；Mozilla 选择优先推进站点隔离而不直接修复。

**推荐理由**：推测执行漏洞的战线从静态二进制转移到了运行时生成的代码，这类防御此前几乎没人系统考虑过。

## [统治 C++ 编译三十年的 EDG 前端开源，交由 C++ Alliance 托管](https://edgcpp.org/)

2026 年 9 月 30 日，EDG（Edison Design Group）的 C++ 前端源码正式公开，非营利组织 The C++ Alliance 成为其新东家。EDG 前端三十年来支撑着整个产业的 C++ 编译工作，是同类中唯一一个生产级质量的**源到源**引擎——Intel、NVIDIA 的 CUDA 前端、各类静态分析与重构工具长期构建于其上。官方措辞强调连续性："这是托管方的更替，不是路线的改变。"选择 C++ Alliance 的理由是三条同时成立：它有成熟的财务托管基础设施、有在职的 C++ 编译器工程师、以及在标准委员会和 Boost 社区的深厚根基。今后 EDG 将按普通开源项目运作，开发分三条轨道：来自用户社区的 PR 贡献（由资深 EDG 开发者评审后合入）、Alliance 工程师的持续维护（即时发布）、以及集体出资的新特性开发。

**推荐理由**：C++ 工具链里最后一块闭源基石开放了，这对静态分析、IDE 和异构编译前端生态的长期影响会慢慢显现。

## [livenerf：一个为期 30 天的预注册实验，用统计方法回答"模型发布后是否被偷偷削弱"](https://github.com/ninjahawk/livenerf)

长期以来社区反复出现"某模型发布几周后变笨了"的说法——可能是量化、换了更小的模型、降低了推理预算，也可能纯粹是噪声中的模式匹配。争论始终停留在体感对体感，因为**没人握有发布当天的干净基线**。livenerf 抓住 Claude Opus 5.5 于 2026-09-22 发布的时间窗，从发布日开始计时。由于采样参数不可见、thinking 无法关闭，模型本身无法做到确定性，于是该项目把其余一切都冻结：固定提示词、锁定 CLI 版本、精确评分器、原始日志永久保留，再在数千个样本上做统计漂移检测。它构建在英国 AI 安全研究所的开源评测框架 Inspect 之上，统计方法直接采用 Anthropic 自己的《Adding Error Bars to Evals》。截至 9 月 30 日已采集 7 天（基线需 10 天），90 样本/天全部跑在同一 harness 哈希与固定 CLI 2.1.280 上，无缺失。首个可能的结论约在 10 月 24 日出现。主要指标是对齐面板的配对逐项分差，次要指标是每样本输出 token 数。

**推荐理由**：预注册协议 + 公开原始日志的做法，是把 AI 社区里最顽固的"玄学争论"之一拽进可证伪范畴的正确姿势。

## [Pi 收回"绝不支持 MCP"的表态：把 MCP 并入内核，并重新定义它该长什么样](https://earendil.com/posts/you-said-no-mcp/)

Earendil 团队曾在官网和播客里高调宣称 Pi 不支持 MCP，如今升级后 MCP 成了内核功能。他们的解释分两层：一是"今天的 MCP 不是去年的 MCP"，二是——更关键的——为支持 MCP 所做的改造本身就是普遍有用的，同样的工作让 Jev 在 Pi 内的使用也更容易了，因为 Pi 需要的东西和 MCP 需要的东西高度相似：一个可供玩耍的解释器沙箱。他们仍然直言 MCP 最大的问题是**难以组合**，即便有 codemode 也未完全解决，但认为这更多是现有 MCP server 的问题：很多 server 是为"把工具一股脑塞进上下文"的 harness 设计的，只好在自己这端返回文本来省 token。团队的主张是 MCP 应当更接近"带智能工具发现的 OpenAPI"——工具返回结构化数据，并可通过文档和描述被发现。Pi 的 MCP 实现建立在把工具暴露给 JavaScript 沙箱之上，与 Codex 等 harness 同路。文章最后点明动机："影响一件事最好的方式是参与它。"

**推荐理由**：一个公开的立场反转，且给出了完整的技术理由链条。对判断 MCP 生态未来两年的走向是罕见的一手材料。

## [SEABench：自进化 agent 会把"局部有用的经验"固化成下游的安全事故](https://www.alphaxiv.org/abs/2609.35596)

弗吉尼亚大学与 ELLIS Institute Tübingen 提出 SEABench，研究一类他们命名为**内生性失准（endogenous misalignment）**的风险：自进化 agent 在无任何对抗性干预下，仅因为响应正常的用户反馈而写入持久更新，这些更新在当时是有用的，却会在后续不适用的语境中造成危害。基准包含 48 条纵向任务序列、480 个任务实例，覆盖控制器文件、记忆、工具/技能三类进化面，以及隐私泄露、语境边界坍塌、幻觉、护栏侵蚀四类危害。关键设计是**配对的非进化 agent** 与归因评分，用于建立因果链接。在 Kimi K2.5、Grok 4.3、GPT 5.6 Luna 上的结果：自进化确实提高任务完成率，但 3435 次尝试中自进化 agent 出现 1105 次安全失败，对照组 833 次（Fisher 精确检验 p = 3.48×10⁻¹³）。**工具/技能面最脆弱，失败率 55.8%**，因为错误在这里变成了可执行、可复用的东西。基于推理链的监控可将控制器与记忆面的危害降低约 90%，但对工具面只有 54.8%——缺陷藏在被调用的能力里，思维链中看不见。

**推荐理由**：它测的不是"agent 被攻击后会怎样"，而是"agent 好好干活也会怎样"。后者才是长期部署真正要面对的问题。

## [RLX：用一份 Rust 代码库统一张量编译器与运行时，同一 IR 从服务器 GPU 直达 INT8 单片机](https://arxiv.org/abs/2609.37916)

MIT 的 Eugene Hauptmann 与 Nataliya Kosmyna 提出 RLX，针对生产 ML 栈把图编译和内核执行拆散在不同层次与语言（通常是 Python 主机 + C++/CUDA 内核）导致行为难以端到端推理的问题。RLX 用一个 Rust workspace 同时承担编译器与运行时角色，围绕一套三层中间表示（HIR 块级算子 → MIR 融合原语 DAG → LIR 带缓冲规划）展开，约 113 个原语算子。同一份 IR 覆盖 **14 种运行时设备**（cpu/metal/mlx/ane/cuda/rocm/oneapi/tpu/hexagon/vulkan/webgpu 等）与两条专用代码生成路径（Cortex-M INT8 和 FPGA→Verilog→比特流），可摄入 safetensors、GGUF、ONNX、rten 四种格式，支持 AMP/PTQ/QAT 与 INT4/INT8 量化，并通过 TCP 与 RDMA 做张量并行/流水并行。区别于同类的关键是**透明派发契约**：每个算子被分类为 native / common-IR / rewritten / 不支持，无法合法化时直接编译失败并给出诊断，而不是静默回退 CPU。评测中 RLX-Metal 在 all-MiniLM-L6-v2 各批量下均最快（batch 32 为 16.6 ms，对 PyTorch-MPS 的 26.7 ms）。

**推荐理由**：同时命中 Rust、AI infra 和模型小型化三条线；"拒绝静默降级"这一设计取向，对做部署的人比跑分有用得多。

## [彭博终端简史：一台把金融数据卖成垄断的专用计算机](https://spectrum.ieee.org/bloomberg-terminal)

IEEE Spectrum 梳理彭博终端的技术源流。文章把金融史重新表述为"信息移动得多快、以及谁控制界面"的历史：1841 年 Mercantile Exchange（邓白氏前身）开始向美国客户出售专有商业信息；1850 年代路透（Paul Julius Reuter）售卖新闻与股价服务，为补充电报调度甚至在亚琛与布鲁塞尔之间放飞信鸽，每只鸟携带装有当日股价纸条的圆筒；1867 年 Edward Calahan 推出首台电报式纸带行情机，爱迪生于 1871 年改进并申请专利；1960 年 Quotron 推出首个无纸化金融服务的电子屏幕。1981 年 Michael Bloomberg 从所罗门兄弟被解雇、带着 1000 万美元股权兑付款创办 Innovative Market Systems 时，面对的是一个已经拥挤的行业。他的差异化在于：终端不仅提供最新信息，还能基于历史数据**即时做定量分析**。文中配图的 1990 年代初彭博键盘带有轨迹球、扬声器以及耳机与麦克风接口。

**推荐理由**：一段被专有硬件、专有键盘和专有数据同时锁定的计算设备史，也是理解"界面即护城河"这一商业模式的最佳案例。

## [Floppy Emu 故障分析月：攒了几年的返修板子拆完，最大元凶是一批被换掉的晶振](https://www.bigmessowires.com/2026/09/29/floppy-emu-hardware-failure-analysis-results/)

Big Mess o' Wires 的作者终于处理了办公室角落里堆积数年的 Floppy Emu（Apple II / Mac 软驱模拟器）QA 失败品与客户返修件，并公布了逐项归因。最大一类源于供应链替换：最近一批生产中常用的时钟晶振缺货，代工厂在他同意下换了同规格的另一型号，"本不该有任何影响，但确实有了"。26 块板子表现为完全没有时钟——微控制器切到外部晶振后毫无反应；另有 16 块能部分工作但行为不稳定或在高频下失败。他最终判断是**装配过程中的粗暴搬运或过热损坏了晶振**，更换并重新编程后全部修复。第二大元凶是 Xilinx CPLD——作为直接连接外部接口的芯片，它承受了所有静电与电气应力的冲击，标称 5V 耐受但在此用法下表现存疑，极端情况下会变成电源对地的硬短路。第三大原因则令人哭笑不得：微控制器**根本没被烧录**。此外还有虚焊、连锡，以及用户把排线反插到 Disk II 控制器（裸针座、无防呆）导致 ±12V 打进 MCU 引脚而烧毁。

**推荐理由**：小批量硬件创业者少见的诚实复盘，"同规格替换件"这种看似零风险的决策如何吃掉整批良率，值得所有做硬件的人读一遍。
