## [OpenAI 年化收入实为 500 亿美元，比此前放风的数字少 180 亿，AI 板块集体下挫](https://www.cnbc.com/2026/10/08/open-ai-revenue-nvidia-oracle-coreweave.html)

OpenAI 在一份投资人材料中确认，截至 9 月底其年化收入约 500 亿美元，而非上月被广泛引用的 680 亿——知情人士称后者把合作伙伴的总收入也算了进去。消息传出后英伟达跌 3%、甲骨文跌近 6%、CoreWeave 跌近 8%，AMD、博通、英特尔、超微同步下挫 4–5%。OpenAI 同时强调第三季度整体 run rate 增长 77%、企业业务增长 107%，并正与投资人初步接触一轮约 300 亿美元的新融资。公司目前估值 8520 亿美元，已于 6 月秘密递交招股书，高管暗示瞄准 2027 年上市。对照之下，Anthropic 7 月底的年化收入为 650 亿美元。

**推荐理由**：整条 AI 基础设施产业链的估值都挂在这一个数字上，口径一变就立刻传导到硬件股。

## [英伟达掏出 10 亿美元押注"创世纪计划"，时隔八年重返美国超算主战场](https://www.theregister.com/hpc/2026/10/08/nvidia-found-1b-under-the-couch-to-help-secure-american-scientific-computing-dominance/5302110)

这笔承诺约为英伟达一个季度利润的六十分之一，将在五年内投向量子计算、医疗和能源安全方向的科研，属于美国政府"Genesis Mission"的一部分。更实质的变化是硬件：能源部上一代英伟达旗舰超算 Summit 与 Sierra 还是 2018 年的事，而去年起英伟达已拿下阿贡、洛斯阿拉莫斯、劳伦斯伯克利三家国家实验室共七台新机，其中阿贡的 Solstice 用 10 万张 Blackwell。代价是精度——近几代 GPU 把 FP64 算力让渡给了更赚钱的低精度 AI 负载，即将到来的 Vera Rubin 平台靠 Ozaki 方案做 FP64 仿真。纯 FP64 最强的橡树岭 Discovery（2029 年）仍将采用 AMD MI430X。

**推荐理由**：科学计算的硬件定义权正从双精度转向 AI 精度，这是一次范式让位而不只是采购新闻。

## [台积电出 20 亿美元找格芯代工硅中介层，美国先进封装的缺口开始补上](https://www.theregister.com/systems/2026/10/08/tsmc-taps-globalfoundries-to-bolster-us-silicon-interposer-production-in-2b-deal/5302061)

格芯将在纽约 Malta 工厂为台积电的 CoWoS 先进封装生产硅中介层，合作期五年、可延长。中介层位于计算裸片与 HBM 之下，为多裸片拼装提供比有机封装更快更省电的互连通路——今天几乎每一颗用 HBM 的芯片都依赖它。先进封装一直是美国本土制造的真正瓶颈：去年台积电亚利桑那厂开始生产英伟达 Blackwell 时，成品仍要运回台湾做最终组装再运回美国。台积电自建的亚利桑那封装厂与 Amkor 的产线要到 2028、2029 年才上线，而格芯 Malta 的量产最早也在 2028 年上半年。

**推荐理由**：芯片本土化的真正卡点一直在封装而非晶圆，这笔交易第一次给出了明确的补缺时间表。

## [数学界开始消化 OpenAI 的 372 项结果：唯一游戏猜想被"证明"，但没人读得懂](https://scottaaronson.blog/?p=10169)

Scott Aaronson 把这一周称为"数学启示录"。他妻子 Dana Moshkovitz 毕生研究的唯一游戏猜想（UGC）出现在 OpenAI 周二公布的 372 项结果中，附有 Lean 证书，但她的阅读体验是："像一个嗑了迷幻药的人写的……不借助 AI 根本读不下去"，证明构造了一种既非 long code 也非 short code 的"外星般怪异"的新编码。迄今几乎没有人类真正理解其中任何一项证明。同一批结果中已有三项被 OpenAI 撤回。Terence Tao 则在 Mastodon 上提出"Math 2.0"：传统数学里一个突破会带来讲座、研讨会、合作与后续问题，而这套机制在成批产出的机器证明面前整个失效。

**推荐理由**：和前天 OpenAI 的自我宣告不同，这是被影响的数学家本人在说话，暴露出的是验证机制而非产出能力的危机。

## [Vitalik 附议"地堡模式"：担心 AI 数学在量子之前就先攻破椭圆曲线](https://cointelegraph.com/news/justin-drake-urges-crypto-bunker-mode-as-ai-could-break-wallet-security-within-months)

以太坊研究员 Justin Drake 周三呼吁行业进入"bunker mode"，建议把资产逐步迁往公钥尚未暴露的新地址，理由是 AI 加速的数学进展可能先于量子计算机攻破 ECDSA。他指出椭圆曲线结构过于丰富（Schoof、Frobenius、配对等"花招"的空间很大），而哈希函数恰恰被设计成尽量不含代数结构。Vitalik Buterin 回应称"今天不必抢着搬钱，但必须认真对待 AI 加速数学对密码学的威胁"，并把担忧扩展到被认为抗量子的格密码——"未来两年的 AI 数学很可能让格的具体安全性挨上重击"，这正是以太坊 lean roadmap 走"纯哈希"路线的主要原因。

**推荐理由**：密码学的安全假设第一次因为"常规数学可能被推翻"而被重估，和量子威胁完全是两套逻辑。

## [十家 AI 巨头向英国监管机构让步，下一个被盯上的是会自作主张的智能体](https://www.theregister.com/ai-and-ml/2026/10/08/ai-giants-promise-to-play-nice-with-personal-data-after-uk-watchdog-scrutiny/5301966)

亚马逊、Anthropic、苹果、Cohere、DeepSeek、谷歌、Meta、微软、OpenAI 与 Stability AI 在英国信息专员办公室（ICO）的监督计划下，已做出或承诺做出整改：更清楚地说明个人信息如何用于训练、提供更可行的数据权利行使途径、对自身保障措施做更严格的评估。该计划 2025 年启动时覆盖 11 家，xAI 因 Grok 被单独立案调查而被移出。ICO 没有宣布收工——模型内部沉淀的个人数据（尤其是敏感信息）如何删除、训练后的模型如何从技术上满足"被遗忘权"、以及个人信息被从模型中反向提取的风险，都仍然没有答案。

**推荐理由**：让企业做出承诺是一回事，让已经训练完的模型事后合规是另一回事，这个缺口监管方自己也承认了。

## [Shai-Hulud 蠕虫跳进 AI 基础设施：Tensorlake 的 npm SDK 被投毒](https://www.theregister.com/security/2026/10/08/shai-hulud-worm-makes-jump-to-ai-infrastructure-with-tensorlake-compromise/5302054)

多家安全机构周四在 Tensorlake SDK 的 npm 包 0.5.144 版中检出 Shai-Hulud 感染，该包周下载约 1.2 万次。这一变种与 8 月攻击 keyv、flat-cache 的 ChainDrop 同源，窃取加密钱包、浏览器密码、GitHub Actions secrets、云凭据和服务账号令牌，并保持 C2 连线待命；更棘手的是它会监控被窃的 GitHub token，一旦发现被吊销就可能在特定条件下删除用户 home 目录。讽刺之处在于 Tensorlake 本是跑隔离 AI 智能体和不可信 AI 生成代码的平台，但 SDK 的安装脚本执行在沙箱之外的开发机或构建机上，继承的是安装进程的权限。Socket 在发布 11 分钟后标记，npm 已下架。

**推荐理由**：把智能体关进沙箱的同时，装沙箱用的 SDK 本身成了最短的那块木板。

## [2100 台 GPU 服务器把英伟达监控端口裸露在公网，附带一个高危漏洞](https://www.theregister.com/security/2026/10/08/high-severity-nvidia-bug-could-crash-gpu-monitoring-on-exposed-servers/5302077)

数据中心安全公司 Lava 的 Michael Katchinskiy 在英伟达 DCGM Exporter 中发现 CVE-2026-47483（CVSS 8.2），未认证攻击者可令 GPU 监控服务崩溃、干扰 AI 负载。三至五月的四轮扫描找到约 2100 台把 DCGM 指标明文暴露在公网的 GPU 服务器，覆盖 1.2 万个 GPU UUID，无一需要认证；这些机器属于约 300 家组织，44%（5274 张卡）位于美国，硬件价值约 1 亿美元，含 Blackwell Ultra B300、H200、H100 以及消费级 RTX 5090/4090。另有约四分之一的主机连 Go 的 `/debug/pprof/` 运行时剖析端点一并敞开。英伟达 9 月已发布修复。

**推荐理由**：AI 集群的暴露面正在被人系统性清点，而硬件清单本身就是一份极好的侦察情报。

## [用 LLM 把 TypeScript 编译器移植到 Rust：GPT 烧了 42 万美元没做成，Opus 两周花 2.4 万做成了](https://github.com/pingdotgg/ts-rust)

Theo（pingdotgg）公开了 ts-rust，一个 TypeScript 7 编译器、类型检查器和 LSP 的 Rust 移植，作为 `tsc-rs` 发布到 npm。他先用 GPT-5.6 Sol 与 GPT-6 Astra 跑了几个月的 `/goal` 循环，写出 130 万行 Rust、烧掉逾 40 万美元 API 等值 token，兼容性始终卡在 84%。换成 Opus 5.5 后，模型从零重写，10 小时拿出可用的 v0，两周共约 2.4 万美元完成——相当于其 200 美元套餐周额度的 925%–983%。作者自称"从没读过这份代码里的任何一行"，README 里专门划了一条"Slop Line"，线以下全部由模型撰写。

**推荐理由**：把"模型能否承担大型移植工程"从讨论变成了带价签的实测，顺带量出了两家模型的效率差。

## [Whistle：16.9 MB 的语音识别模型，首 token 11 毫秒，和小语言模型共用一个 C++ 引擎](https://cactuscompute.com/blog/whistle)

Cactus 发布的 Whistle 是单个 16.9 MB 文件，纯 CPU、无依赖，支持七种语言，面向手机、可穿戴、机器人、智能家居、车机和微控制器。它与该公司的 Needle 文本模型共用 Simple Attention 模块、同一容器和同一量化方案，因此一个二进制既能做语音也能做文本，可以把一段音频直接变成工具调用。架构上编码器八层非因果注意力，解码器通过门控交叉注意力读取编码器，K/V 每段音频只投影一次供五路 beam 共享。词错率在 LibriSpeech test-clean/other、SPGISpeech、Earnings-22 和 FLEURS 上优于 145.3 MB 的 Whisper base，TED-LIUM、AMI 与 MLS 则落后。

**推荐理由**：端侧 ASR 做到十几兆还在多项基准上压住 Whisper base，语音入口的部署成本被重新定价。

## [MIT 论文：大模型可以被训练成容忍硬件出错，而且越大越抗错](https://arxiv.org/abs/2610.10311)

Trevor McCourt、Ila Fiete 与 Isaac Chuang 用 4 万 GPU 小时在模拟的故障数字硬件上做训练，拟合出修正版的神经网络缩放律：LLM 在不可靠硬件上的容错能力不但没有随规模恶化，反而随规模增强。作者的解释是模型学会了在"良好"的纠错码内部完成计算，而这种码的相对开销无论模型多大都保持有限。据此他们提出一个猜想——经过适当训练的 LLM 可能是形式意义上容错的；若成立，在低功耗、会出错的硬件上做推理就有望带来相对现状可观的能耗节约。

**推荐理由**：新兴硬件普遍拿可靠性换能效，这篇把"模型自己扛错"从工程权宜变成了可以推导的缩放律问题。

## [把 AI 智能体装进诺基亚 110 4G：从计算器入口加载，跑在功能机原生功能上](https://github.com/anupray95/AI-Agent-on-a-NOKIA)

作者逆向了诺基亚 110 4G 的固件与启动流程，在没有任何受支持的安装途径的情况下，借计算器程序的入口把自定义代码加载进 RAM，改造成一个聊天应用：用数字键盘打字，消息发往 DeepSeek chat API，模型通过工具调用操作手机本身——查 SIM 卡数据、读电量、开关手电筒、拨打电话、设置闹钟。整个流程拔掉 USB 后靠移动数据独立运行。推进过程分四阶段，最难的一步是追踪固件的响应回调，因为早期请求能发出去却收不到回答。目前仍是原型：断电或重启后需要重新加载，永久安装尚未解决。

**推荐理由**：在一台没有应用生态的功能机上把 LLM 接到原生系统调用，是智能体下沉到廉价硬件的一个极端样本。
