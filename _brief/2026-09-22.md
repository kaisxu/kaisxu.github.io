## [小米 MiMo-V2.6 技术报告：1.02T 参数 MoE，把 RL 算力堆到极限](https://www.alphaxiv.org/abs/2609.mimo-scaling-reinforcement-learning)

小米 LLM-Core 发布 MiMo-V2.6 系列：Pro 版 1.02T 总参数、42B 激活，Flash 版 310B/15B 激活，均为 hybrid-SWA（128 窗口滑动注意力与全局注意力交替）稀疏 MoE 全模态架构。核心是沿三个维度扩展 RL 算力——单步 1568 条样本、2.7~3.7B token、上下文长达 1M 的异步训练；覆盖代码、通用、视觉、网络安全四类环境与多种 agent harness；以及"分组式 agent 评分"（GRS/GAR）把同组解法互相比较，从而给出比二值测试用例更细的奖励信号。为稳住大规模训练，团队冻结 MoE router 并搭了多层防 reward hacking 机制。DeepSWE v1.1 得 71.9，Terminal Bench 2.1 得 89.9，与 Claude Opus 5、GPT-5.6 Sol 同档。开源的是蒸馏小模型 MiMo-V2.6-Distill-Qwen-9B 加 RL 环境、框架和 mini-harness，而非主力权重。

**推荐理由**：少见地把 agentic RL 的基建细节（训推一致性、R3 路由重放、top-p 候选集重放、上下文缓存分层卸载）写得这么透，是工程向读者的富矿。

## [xAI 发布 Grok 4.7：同价同速，主打长任务的自我校验](https://x.ai/news/grok-4-7)

9 月 21 日发布，官方定位为"编码与知识工作上最强"的模型，宣称比同档竞品快一倍、便宜一半。定价 $2/百万输入 token、$6/百万输出 token，另有 2 倍价格的加速版；与 Grok 4.6 保持同价同速。改进来自更大的基座模型加上针对"数小时级难任务"的延长强化学习，具体提升在工作结果自查、上下文管理和对话能力三处，后者通过原生 Grok Bot 集成实现。公布的基准包括 CursorBench 4.0 的 46.3%、DeepSWE v1.1 的 71.0%、EEBench 的 64.0%、Harvey 法律 agent 基准的 19.6% 和 HealthBench Professional 的 56.7%。目前可经 Cursor、Grok Build、Grok API 及第三方平台调用，页面未披露最大上下文长度。

**推荐理由**：Harvey 法律基准只有 19.6%，和编码分数的落差恰好说明"通用能力"在垂直专业域仍有硬边界，比单看 SWE 分数有信息量。

## [Cloudflare Python Workers 正式 GA：FastAPI、Django 都能跑在边缘](https://blog.cloudflare.com/python-workers-ga/)

Cloudflare 宣布 Python 成为其开发者平台的一等公民，Python Workers 脱离 beta 进入生产可用。关键推力是 PEP 783 对 PyEmscripten 平台标签的标准化，使得带原生扩展的包可以发布交叉编译到 WebAssembly 的 wheel，从而打开了此前封闭的生态。官方点名支持的包括 FastAPI、Django、Flask 三大 Web 框架，OpenAI、LangChain、MCP 等 AI 库，以及经 Hyperdrive 接入的 aiomysql、asyncpg 数据库驱动。限制也写得直白：含 C/C++/Rust 原生扩展的包必须先交叉编译到 Wasm，而目前并非所有包都已提供 PyEmscripten wheel，生态仍在适配中。公告未给出冷启动时延和定价数据，只提到后续会继续优化性能与内存占用。

**推荐理由**：PEP 783 落地意味着"Python 跑在 Wasm 上"从玩具走向工程可用，这是 Python 部署形态近年最实质的一次扩张。

## [AWS 开源 Strands Harness：号称比同行少烧 28% token](https://www.theregister.com/ai-and-ml/2026/09/21/aws-bolts-together-open-source-agent-harness-says-it-sips-fewer-tokens-than-rivals/5297915)

AWS 发布开源 agent 框架 Strands Harness，提供 Python/TypeScript 库和 CLI，设计上开箱即用、可对接多家模型供应商，内置 shell、文件和 Web 工具。AWS 称其在六项基准测试中比 Claude 与 GPT 系模型少消耗 28% 的 token，同时分数与 Claude Code、Codex 等流行框架接近；不过 AWS 自己也承认 DeepSeek 的 harness token 效率更高，只是准确率较低。省 token 来自几项默认开启的优化：prompt 缓存、超过 1500 token 的工具结果自动截断、上下文用量达 85% 时自动压缩，以及溢出后的恢复机制。The Register 点出了要害——这是一个通用框架拿去和纯编码 agent 比，且全部基准由 AWS 自测，尚无独立复现。

**推荐理由**：上下文压缩策略（1500 token 截断、85% 触发压缩）是可直接抄进自家 harness 的具体数字，比营销口径的"省 28%"有用得多。

## [Tim Dettmers 的 DLab 开源周：550B 模型跑在 128GB 的 MacBook 上](https://timdettmers.com/2026/09/21/dlab-open-source-week/)

量化领域知名研究者 Tim Dettmers 一次性放出两个开源项目和四篇论文，组成一整套本地化推理与研究栈。项目包含一个支持长时间自主研究会话的 agent harness，以及针对 CUDA、Metal、AMD 三路后端优化的推理框架；配套的 CliffCompaction 自动压缩技术宣称在延长 agent 会话的同时把成本砍掉约一半。硬件门槛给得很具体：125B 参数的 Qwen 3.8 Flash Next 跑在单张 24GB 显卡上，550B 的 DeepSeek V4.1 跑在 AMD Strix、NVIDIA DGX Spark 或 128GB 内存的 MacBook 上；1.5 bit/权重量化下 Qwen 3.6 35B-A3B 可达 450 token/秒。Dettmers 的论点是学术实验室可以靠"创造力、时间和自由"而非算力规模参与前沿竞争，并称其本地自主研究系统跑赢了 Sakana AI 与 Google ScientistOne。

**推荐理由**：把"本地能跑多大模型"的上限抬高了一个数量级，对关心端侧部署和小型化的人是今年最值得跟进的一份工作。

## [AMD 市值破万亿：数据中心份额 34.5%，但仍是英伟达的五分之一](https://www.theregister.com/systems/2026/09/21/perpetual-underdog-amd-nips-at-nvidias-heels-as-it-joins-the-1t-club/5297998)

AMD 周一盘中市值短暂突破一万亿美元，成为少数跻身该俱乐部的芯片设计公司，同时已反超估值 6400 亿美元的英特尔。但差距依然悬殊——英伟达以近 5.5 万亿美元稳居全球市值第一。推力来自 AI：2023 年的 Instinct MI300A 和后续 MI350 系列在性能上追平或超越英伟达，同时价格更低、显存更大，拿下了微软、OpenAI、Meta 和 Anthropic 的大单。2026 年中 AMD 称其 Helios 机架系统比英伟达对位产品多出 50% 的 HBM4 与 scale-out 带宽，AI 训练性能高 15%~25%。CPU 侧同样出力，Epyc 在数据中心份额 8 月达 34.5%，只与 Intel Xeon 对比时则为 46.4%。文章还指出 AMD 横跨 CPU、GPU、FPGA 和网络的产品结构，反而比重仓 AI 加速器的英伟达更抗 AI 泡沫风险。

**推荐理由**：把"AMD 追上来了"这个模糊印象落到市值、份额、带宽的具体数字上，也顺带点出了两家在泡沫敞口上的结构性差异。

## [Anthropic 关联 CVE 堆积到 225 个，攻击者却基本无动于衷](https://www.theregister.com/security/2026/09/21/anthropic-linked-cves-pile-up-attackers-mostly-shrug/5298018)

Anthropic 的 Project Glasswing 已累计发现 225 个漏洞——参与者使用 Claude Mythos Preview 对自家产品和开源依赖做防御性安全工作——但其中仅有一个确认遭到实际利用：Ghost 的一个严重 SQL 注入缺陷 CVE-2026-26980。安全研究者 Patrick Garrity 解释了这一落差："我们看到的很多歇斯底里，都假定每个漏洞或 bug 都会被威胁方利用。"历史数据显示只有 1%~2% 的已披露漏洞最终被武器化，AI 提升了发现能力，也不改变这个比例。文章给出两点原因：其一，修补仍高度依赖人工，研究显示 AI 生成的补丁只有 26% 能完全修复问题，54% 会失败或引入新缺陷；其二，协调、定级、修复与补丁分发这些下游环节仍是人力瓶颈，反而形成了攻击者难以利用的时间差。

**推荐理由**："AI 大批量挖洞会引发安全危机"是过去一年最流行的叙事之一，这篇用发现量与实际利用量的对比，给出了少见的反面证据。

## [Apple Copland 末版 D11E4 首次在浏览器里跑起来了](https://www.pagetable.com/300)

Copland 是苹果那个流产的微内核操作系统，原计划接替 System 7；项目烂尾后苹果转而收购 NeXTSTEP/OpenStep，才有了后来的 Mac OS X。这次能跑起来的是 D11E4——该系统的最后一个构建版本。Copland 此前以"在真机上极难运行"著称，且从未有过可用的模拟方案。作者基于改进版 DingusPPC 模拟器编译到 WebAssembly，并打了十一个补丁才让它成功引导，补丁分散在两个 GitHub 分支上有完整记录。在现代机器上约 30 秒实时即可完成启动，交互时点击屏幕或按 Esc 切换键鼠捕获，代码触发断言时会弹出调试器；进系统后可以在 Applications 文件夹里打开 GXSlidemaster 或 Eric's Solitaire 这类当年的应用。

**推荐理由**：计算机史上最著名的流产操作系统之一，第一次变成任何人打开浏览器就能摸到的东西，保存与考古意义都很足。

## [一台修复好的 PDP-11/83 正在用 2.11BSD 给你发网页](http://pdp1173.com/)

这台 PDP-11/83 以 Mentec M11 单板处理器（集成内存）替换了早期的多板方案，跨两个 Q-bus 机箱互连以扩展存储和 I/O。存储配置相当完整：三台 RA 系列硬盘（一台 RA82、两台 RA92），外加老式 RL02 驱动器、RX50 软驱和一台 TKZ50 磁带机；网络经 DEQNA 以太网控制器接入，串口终端走 M3104 多路复用器。系统跑的是 2.11BSD，这一 PDP-11 上的 Unix 分支原生支持 C 编译与网络，机器上运行着一个小型 HTTP 服务器和带缓存的 TMOG-11 采样器，实时展示内核与进程活动——你看到的那个仪表盘正是它自己发出来的。为了不压垮老硬件，页面做了多级缓存：共享的 TMOG-11 快照缓存 5 秒，浏览器标签隐藏时暂停更新，前端缓存再削减重复请求。

**推荐理由**：不是静态展品而是真在对外提供服务，连缓存策略都是围绕"这台机器算力有限"设计的，把复古计算的工程约束讲得很实在。

## [爱尔兰数据保护委员会对谷歌开出 4.03 亿欧元罚单](https://www.dataprotection.ie/en/news-media/latest-news/data-protection-commission-fines-google-eu403-million-following-inquiry-googles-processing-location)

爱尔兰 DPC 认定谷歌在位置数据处理上违反 GDPR，处罚 4.03 亿欧元。违规涉及三项服务：Web & App Activity（浏览与搜索记录）、Location History（到访地点与移动轨迹）、Location Accuracy（安卓设备定位）。具体认定包括前两项在处理位置数据上的合法性与公平性缺失、Location Accuracy 的问责义务缺失、三项服务均未尽透明度义务，以及位置数据留存期过长。违规时间窗为 2018 年 5 月 25 日至 2020 年 2 月 4 日。副专员 Graham Doyle 表示，用户"可能并不知道自己的位置正被用于"定向广告，加之留存期过长，实际上无法对个人数据保持控制。谷歌须在六个月内完成整改。

**推荐理由**：认定的四类违规里"留存期过长"和"问责义务"两项最少被讨论，却是最可能波及其他做位置业务公司的判例点。

## [长鑫存储 CXMT 称 DRAM 密度翻倍，推出 24GB LPDDR5X](https://www.theregister.com/systems/2026/09/21/chinese-memory-maker-cxmt-claims-dram-production-breakthrough/5297633)

中国存储厂商长鑫存储（CXMT）宣布其第五代制程实现突破，称该工艺"基本上让内存密度翻倍，意味着同一张晶圆可以切出两倍数量的内存裸片"。关键创新是把 high-k 介电层金属栅（HKMG）工艺适配到 DRAM 制造上。公司同时发布了面向智能手机和消费电子的 LPDDR5X 内存模组，两款产品均为 24GB 容量。The Register 指出报道中未涉及 HBM 相关内容。市场影响上，若密度提升与量产宣称属实且价格有竞争力，对正面临 AI 产品需求推高内存价格、苦于缺货的中国电子制造商是利好；但西方国家政府对采用中国产元器件仍有顾虑，这一技术成果的市场渗透范围可能因此受限。

**推荐理由**：在 HBM 被抢光、DRAM 全面涨价的当口，供给侧多一个变量就值得记一笔，哪怕它暂时够不到 HBM 这一层。

## [《Attention is all you have》：算法信息流正在重写你的思维模式](https://alicegg.tech/2026/09/21/attention)

作者借用"俄罗斯方块效应"——长时间玩俄罗斯方块后连现实中的物体都会下意识地想去拼合——论证专注于什么就会重塑思考方式，而以最大化停留时长而非服务用户为目标的算法信息流，正是在这个机制上做文章。文中点名 YouTube、Spotify 和 LinkedIn 按互动指标而非用户偏好排序，塞进大量并不反映真实兴趣的内容，因为"刷到抑郁会让你待得更久、多点几个广告"。作者还观察到平台上低质量 AI 生成内容和伪装成真人发言的机器人日益增多，进一步侵蚀了信息可靠性。对照之下，算法出现之前的互联网需要靠书签和 RSS 主动导航，这种天然摩擦反而挡住了算法操纵。给出的对策是回到更慢、更有意图的上网方式：博客、RSS、教程，代价是要刻意重建习惯。

**推荐理由**：标题是对 Transformer 论文的双关，论证却落在认知自主权上；把"注意力经济"这个老话题接到了 AI 生成内容泛滥的新语境里。
